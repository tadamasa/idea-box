# Chrome拡張「idea-box に送る」

PCのChromeで開いているページや、選んだ文を、idea-box の受信箱に送ります。

## 入れ方(最初の1回)

1. このリポジトリをダウンロードします(GitHubの「Code」→「Download ZIP」を展開)。
2. Chromeで `chrome://extensions` を開き、右上の「デベロッパーモード」をオンにします。
3. 「パッケージ化されていない拡張機能を読み込む」を押し、展開したフォルダの中の `extension` フォルダを選びます。
4. ツールバーのパズルの印から「idea-box に送る」をピン留めします。

## 設定

ポップアップの「設定」を開き、アイデアハブのURLと合言葉を入れて保存します(ハブの作り方は `hub/README.md`)。

- ハブを設定したとき: タブを開かずに送ります。iPhoneでもPCでも、次に idea-box を開いたときに受信箱に入っています。
- ハブを設定していないとき: idea-box を新しいタブで開いて、そのタブの受信箱に入れます(このPCのChromeの中だけに保存されます)。

## 使い方

- ツールバーのボタン: タイトル・URL・選んだ文が入った状態で開きます。一言メモとタグを足して「受信箱に送る」。
- 右クリック: ページ・選んだ文・リンクの上で「idea-box に送る」を選ぶと、そのまま送ります(ボタンに ✓ が出ます)。
