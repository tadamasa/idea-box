# idea-box

思いつき・Webのリンク・名言・動画・文字の写った写真を、目的を決めずに放り込み、タグでゆるくつなぎ、必要なときにまとめて、必要ならアクションを付けるための、自分専用のアプリです。

- iPhone: ホーム画面のアプリとして、その場の記録・確認・検索
- PC: 同じアプリをブラウザで開いて、タグの整理・まとめ
- Chrome拡張: 開いているページや選んだ文を1クリックで送る
- iOSショートカット: 共有シートからURLや写真(文字をiPhone内で読み取り)を送る

構想は [Zettelkasten型アイデア管理アプリ 構想・設計提案](https://claude.ai/artifact/73YAkJxViteuTdfVKvpLQ3) にあります。この版はその Phase 0(放り込む・タグでつなぐ・アクション・端末間の同期)です。

## しくみ

[reading-memo](https://github.com/tadamasa/reading-memo) と同じ構成です(docs/home-app-architecture.md)。

- ビルドなしのPWAを GitHub Pages で配信。データは各端末の IndexedDB が正本。
- 端末間は、自分のスプレッドシート + Apps Script(アイデアハブ、`hub/`)で差分同期。
- すべてが「カード」で、タグもカードの一種です。タグのページには説明やまとめを書けます。タグのidは名前から決まるので、2台で同じタグを作っても1つにまとまります。
- 受信箱はありますが、件数のバッジや催促は出しません。✓で受信箱から出すのも、出さずに置いておくのも自由です。
- 近いカード: 同じタグと、本文の言葉の重なり(文字の2-gram)から選びます。AIは使っていません。
- 一覧のカードには、写真・YouTubeのサムネイル・Webページの代表画像を小さく出します。Webページの画像はハブ(またはChrome拡張)が取ってきます。YouTubeのサムネイルは i.ytimg.com から読み込みます。
- つながりの紋章: カードごとに、つながりから小さな模様を作ります。外の点はタグ(24か所、タグ同士は重ならないよう作った順に置く)、中心の弧はプロジェクト、外枠の刻みはつないだカード(つながった二枚には同じ刻み)。色は使いません。つながりが似たカードは模様も似るので、一覧を眺めるだけで近さが見えます。
- プロジェクト: ゴールのあること(引っ越し、論文、資格など)をまとめる場所です。手順・つないだ情報・ほかのプロジェクトへのつながりが集まります。
  - 手順もカードです。別のプロジェクトへ移せて、「この手順をプロジェクトにする」でサブプロジェクトが生まれます。プロジェクト同士は親子ではなく横のつながりで、片方で付ければ両方から見えます。
  - プロジェクトには色を1つ選べます。つながっているカードの題名の前にその色の点が付き、複数のプロジェクトにつながるカードは1つの点を円グラフのように塗り分けます(4つまで)。一覧にはつながっているカードの数が出ます。
  - アクション画面には、単発のアクションと、期限を付けた手順だけが出ます。期日(期限切れ・今日まで・7日後まで・期日なし。「〜まで」は期限切れも含みます)、プロジェクト、タグで絞り込め、並び順も選べます。条件はこの端末に覚えておきます。
  - 閉じるときに一言だけメモを残せます。定期的な振り返りはありません。
- Gemini は、写真の文字読み取りと、プロジェクトの手順案に使います。どちらもボタンを押したときだけで、手順案で送るのはプロジェクト名・ゴール・期日・メモ・今ある手順・つないだ情報の見出しです。
- 設定は右上の歯車から開きます。

## はじめ方

1. このリポジトリの Settings → Pages で、Branch を `main` / `/(root)` にして保存します。数分で https://tadamasa.github.io/idea-box/ が開けます。
2. iPhoneのSafariで開き、共有ボタン →「ホーム画面に追加」。以後はホーム画面のアイコンから開きます。
3. 端末間で同期するなら、`hub/README.md` の手順でアイデアハブを作り、アプリの「設定」に URL と合言葉を入れます。
4. Chrome拡張は `extension/README.md`、iOSショートカットは `docs/shortcuts.md`。どちらもハブに直接送ります。

## 開発

```
npm test        # 画面に触れない処理と、hub/Code.gs を模擬環境で確かめる
npm run serve   # http://localhost:8765/
```

ファイルを足したら `sw.js` の SHELL に加え、出すたびに VERSION を上げます。
