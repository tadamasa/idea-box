# アイデアハブ(スプレッドシートとの同期)

idea-box のカードを自分のGoogleスプレッドシートに置いて、iPhone・PC・Chrome拡張・iOSショートカットの間で共有するための受け口です。費用はかかりません。

- アプリのデータは今まで通り各端末の中にあり、開いたときと、書いてから数秒後に、変わった分だけをやり取りします。
- 同じカードを二つの端末で直したときは、後から直したほうが残ります。削除も伝わります。

## 準備(最初の1回、パソコンで行うのが楽です)

1. Googleドライブで新しいスプレッドシートを作ります(名前の例: アイデアハブ)。
2. メニューの「拡張機能」→「Apps Script」を開きます。
3. 最初からある `コード.gs` の中身を全部消して、[Code.gs](https://raw.githubusercontent.com/tadamasa/idea-box/main/hub/Code.gs) の中身を貼り、保存します。
4. 上の関数の選択欄で `setup` を選び、「実行」を押します。
   - 権限の確認が出たら、自分のアカウントを選び、「詳細」→「(安全ではないページ)に移動」→「許可」と進みます。自分で作ったスクリプトなので問題ありません。
   - 下の実行ログに「合言葉: …」が出ます。これを控えます。
5. 右上の「デプロイ」→「新しいデプロイ」を開き、種類の歯車から「ウェブアプリ」を選びます。
   - 次のユーザーとして実行: **自分**
   - アクセスできるユーザー: **全員**
   - 「デプロイ」を押し、出てきた「ウェブアプリのURL」(`…/exec` で終わるもの)をコピーします。
6. idea-box の「設定」→「アイデアハブ」に、URLと合言葉を入れて「接続して同期する」を押します。
7. PCのブラウザでも同じアプリ(https://tadamasa.github.io/idea-box/)を開き、同じURLと合言葉で接続します。
8. Chrome拡張(`extension/README.md`)とiOSショートカット(`docs/shortcuts.md`)にも、同じURLと合言葉を入れます。

URLと合言葉を知っている人は読み書きできるので、他の人には教えないでください。

## スクリプトを新しくするとき

Code.gs を貼り替えて保存したら、「デプロイ」→「デプロイを管理」→ 鉛筆の印 → バージョン「新バージョン」→「デプロイ」。URLは変わりません。

## シートの中身

シート `cards` に1行1カードで入ります。主な列は kind(種類)、title、tags(タグ名をカンマ区切り)、inbox(受信箱にあるか)、action・due・done(アクション)、url、createdAt です。

- `deleted` が `true` の行は削除済みです。
- タグもカードの一種で、kind が `tag` の行です。
- 最後の `json` 列がアプリの元データです。表を手で書き換えても、アプリには反映されません。
- 写真そのものは入りません(読み取った文字だけが入ります)。
