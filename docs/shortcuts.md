# iPhoneの共有シートから送る(iOSショートカット)

Safariのページ、他のアプリのテキスト、看板や書類の写真を、共有シートから idea-box の受信箱に送るためのショートカットです。

送り先はアイデアハブ(`hub/README.md` で作るスプレッドシート)です。iPhoneでは、ショートカットからURLを開くとホーム画面のアプリではなくSafariのタブで開いてしまい、保存場所が別になるため、ハブに直接送る方式にしています。送ったカードは、次に idea-box を開いたときに同期で受信箱に入ります。

先にハブを作り、URL(`…/exec`)と合言葉を控えておいてください。

## 作り方

「ショートカット」アプリで、右上の「＋」から新規作成し、次のアクションを順に置きます。表記はiOSのバージョンで少し違うことがあります。

1. 下の「ⓘ」(詳細)で「共有シートに表示」をオンにし、受け取る種類を **URL・テキスト・画像・Safari Webページ** にします。入力がないときは「入力を要求」にしておくと、ホーム画面から開いたときに文字入力になります。
2. **「If」**: 「ショートカットの入力」が「画像」の**とき**
   - **「画像からテキストを抽出」**(入力: ショートカットの入力)
   - **「変数を設定」**: 名前 `本文`、値 = 抽出されたテキスト
   - **「テキスト」**: `photo` → **「変数を設定」**: 名前 `種類`
3. **「その他の場合」**
   - **「変数を設定」**: 名前 `本文`、値 = ショートカットの入力
   - **「テキスト」**: (空のまま) → **「変数を設定」**: 名前 `種類`
4. **「If の終了」**
5. **「入力を要求」**(任意): 質問 `一言・#タグ(空でも可)`、種類 テキスト → **「変数を設定」**: 名前 `一言`
6. **「辞書」**を作り、次の項目を入れます。
   - `token`(テキスト): 控えた合言葉
   - `capture`(辞書):
     - `text`(テキスト): 変数 `本文` と、改行のあとに変数 `一言`
     - `kind`(テキスト): 変数 `種類`
     - `source`(テキスト): `ios-shortcut`
7. **「URLの内容を取得」**
   - URL: 控えたハブのURL
   - 方法: **POST**、本文を要求: **JSON** にして、ファイルの代わりに 6 の辞書を渡します(「JSON」を選ぶと項目を直接入れる欄が出る場合は、そこに `token` と `capture` を入れても同じです)。
8. **「通知を表示」**: `idea-box に送りました`

名前は「idea-box に送る」などにしておきます。

## 使い方

- Safariで共有ボタン →「idea-box に送る」: ページのURLが入ります。
- 写真アプリで看板や書類の写真を共有 →「idea-box に送る」: 写真の文字をiPhoneの中で読み取って、その文字を送ります。写真そのものは送りません(Googleにも送りません)。
- 一言の欄に `#ブログ` のように書くと、本文に入ります。タグとして付けたいときは、idea-box でカードを開いて付けてください。

## うまくいかないとき

- 通知が出ても受信箱に来ない: idea-box の設定で同期が「同期済み」になっているか確かめます。
- 「unauthorized」: 合言葉が違います。
- HTMLが返ってくる: ハブのURLが `…/exec` で終わっているか、デプロイの「アクセスできるユーザー」が「全員」か確かめます。
